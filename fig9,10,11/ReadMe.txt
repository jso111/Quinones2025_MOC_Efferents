This folder contains the data, analysis, and statistics for Figs 9, 10, and 11

In Matlab, run the program "analyzeData.m" to analyze the data and create the plots. In the code, you can see the data that is loaded in: "dataAll.mat".

then, 

In R Studio, run "analyzeStats.R" to do all of the statistical analyses. It will call the function "compareTuningCurves.R". So, please make sure that all of the packages that both of these filed have been installed. If you get an error, it's probably because you didn't install everything.

The result of this R analysis was copied and pasted into the word document "StatsFig9,10,11.docx". All the statistical breakdowns are there, if you are interested.
